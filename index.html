Matrices & Determinants
5 marks · Short answer · [1+1+1+1+1] or [2+3] sub-parts
✅
You already know algebra — this is your most reliable 5 marks. Q12 is always Matrices. Most sets break it into 5 one-mark definition/property sub-questions, so even partial knowledge scores well.
PATTERN 1 Five 1-mark sub-questions on matrix definitions & properties Sets 2, 4, 5, 7 — Most common
Define: symmetric matrix / skew-symmetric / inverse matrix / odd function / complex number absolute value. Write one property of determinant. State condition for BA to be possible. Write A = ½(A+Aᵀ) + ½(A−Aᵀ).
Set 2Set 4Set 5Set 7
PATTERN 2 Find domain & range of a function + matrix property Sets 8, 10 — Common
Find domain and range of y = √(x²−3x+2) or similar. Find B−A for given matrices. Solve quadratic inequality. This pattern mixes functions and matrices in one Q12.
Set 8Set 10
PATTERN 3 Show f(x) = 3x+5 is bijective on Q→Q, find f⁻¹ Set 6 — Function proof
Show the function is one-one and onto. Find inverse. f⁻¹(x) = (x−5)/3.
Set 6
📐 Essential Formulas
Symmetric: A = Aᵀ (Aᵀ means transpose)
Skew-symmetric: A = −Aᵀ
Decomposition:
A = ½(A+Aᵀ) + ½(A−Aᵀ)
Inverse exists if: |A| ≠ 0
A⁻¹ = (1/|A|) · adj(A)
For 2×2: if A = [[a,b],[c,d]]
A⁻¹ = (1/ad−bc) · [[d,−b],[−c,a]]
AB possible if: cols of A = rows of B
Order of AB: m×p (if A is m×n, B is n×p)
🗂️ Key Definitions to Memorise
  • Identity matrix (I): square matrix with 1s on diagonal, 0s elsewhere; AI = IA = A
  • Singular matrix: |A| = 0 (no inverse exists)
  • Non-singular: |A| ≠ 0 (inverse exists)
  • Cofactor: (−1)^(i+j) × minor
  • Adjoint: transpose of cofactor matrix
  • Transpose property: (AB)ᵀ = BᵀAᵀ
  • Property of det: |AB| = |A||B|; |Aᵀ| = |A|
⚡ Minimalist Strategy
Q12 is almost always five 1-mark sub-questions. You do NOT need to solve long problems — just write clean one-line definitions. Memorise: symmetric, skew-symmetric, inverse, adjoint, singular/non-singular, order of AB, and the decomposition formula. That alone covers every sub-question seen across all sets.

Set 1Set 3Set 7Set 8
PATTERN 3 A.M., G.M., H.M. relation proof or sequence problem Sets 6, 9 — Common
Sum of areas of squares (infinite GP). Define AM, GM, HM, show AM > GM > HM. Or: if a,b,c in GP and a,x,b in AP and b,y,c in AP, prove x,b,y in GP. [3 marks]
Set 6Set 9
📐 Key Formulas — Quadratic Roots
For ax² + bx + c = 0, roots α and β:
Sum: α + β = −b/a
Product: αβ = c/a
Discriminant: D = b²−4ac
Equal roots: D = 0 → b²=4ac
No real roots: D < 0

New equation from roots:
x² − (α+β)x + αβ = 0
📐 Key Formulas — Sequences
AP: tₙ = a+(n−1)d
GP: tₙ = arⁿ⁻¹
Sum AP: Sₙ = n/2[2a+(n−1)d]
Sum GP: Sₙ = a(rⁿ−1)/(r−1) r≠1
Sum GP∞: S∞ = a/(1−r), |r|<1
AM: A = (a+b)/2
GM: G = √(ab)
HM: H = 2ab/(a+b)
Relation: A·H = G² ; A > G > H
🔢 Steps: Prove Set Identity e.g. A∪(B∩C) = (A∪B)∩(A∪C)
  1. Step 1 (→): Let x ∈ A∪(B∩C). Then x∈A OR x∈(B∩C).
  2. Case 1: x∈A ⟹ x∈A∪B AND x∈A∪C ⟹ x∈(A∪B)∩(A∪C) ✓
  3. Case 2: x∈B∩C ⟹ x∈B and x∈C ⟹ x∈A∪B and x∈A∪C ⟹ x∈(A∪B)∩(A∪C) ✓
  4. Step 2 (←): Reverse: Let x∈(A∪B)∩(A∪C). Then x∈A∪B and x∈A∪C.
  5. If x∉A: then x∈B (from x∈A∪B) and x∈C (from x∈A∪C) ⟹ x∈B∩C ⟹ x∈A∪(B∩C) ✓
  6. Conclude: Both sides contain the same elements ∴ LHS = RHS □
⚡ Minimalist Strategy
For set proofs: always do a two-direction element-wise proof (show x∈LHS⟹x∈RHS, then x∈RHS⟹x∈LHS). For the quadratic root proof questions, the key is always to write α+β = −p/q and αβ = p/q first, then manipulate. The infinite GP square area problem always uses S∞ = a/(1−r) — memorise this formula cold.

Vectors — Coplanar, Linear Dependence & Combinations
5 marks · [3+2] sub-parts
📌
Q15 is always vectors across every single set examined. The two dominant patterns are: (1) prove three vectors are coplanar, and (2) express a vector as a linear combination or show two vectors are linearly dependent/independent.
PATTERN 1 Show that three given vectors are coplanar Sets 1, 3, 5, 6, 8 — Most frequent
Given: a⃗ − 2b⃗ + 3c⃗, −2a⃗ + 3b⃗ − 4c⃗, −b⃗ + 2c⃗ are coplanar where a⃗, b⃗, c⃗ are any three vectors. Write as linear combination and show the determinant of coefficients = 0. [3 marks]
Set 1Set 3Set 5Set 6Set 8
PATTERN 2 Express vector r⃗ as linear combination of two given vectors Sets 5, 9 — Common
r⃗ = (8,−5), a⃗ = (2,−3), b⃗ = (−1,−2). Find scalars x, y such that r⃗ = xa⃗ + yb⃗. Set up 2 equations: 2x−y=8 and −3x−2y=−5. Solve. [2 marks]
Set 5Set 9
PATTERN 3 Show vectors are linearly dependent/independent; find λ for collinear vectors Sets 5, 9, 10 — Common
If a⃗ = (1,2) and b⃗ = (−3,n), find n for a⃗ and b⃗ collinear. Use: a⃗ ∥ b⃗ ⟺ a₁b₂ − a₂b₁ = 0. OR: show a⃗, b⃗ are linearly dependent if one is scalar multiple of other. [2 marks]
Set 5Set 9Set 10
📐 Coplanar Test Formula
Three vectors p⃗, q⃗, r⃗ are coplanar if
r⃗ = αp⃗ + βq⃗ for some scalars α, β

OR if their scalar triple product = 0:
p⃗ · (q⃗ × r⃗) = 0

For vectors expressed in terms of a⃗, b⃗, c⃗:
p⃗ = l₁a⃗+m₁b⃗+n₁c⃗
q⃗ = l₂a⃗+m₂b⃗+n₂c⃗
r⃗ = l₃a⃗+m₃b⃗+n₃c⃗
Coplanar if det|lᵢ mᵢ nᵢ| = 0
📐 Linear Dependence Formulas
Collinear (2D): a⃗∥b⃗ ⟺ a₁b₂−a₂b₁ = 0

Linear combination:
r⃗ = xa⃗ + yb⃗
→ write component equations
→ solve simultaneously

Linearly dependent:
vectors p⃗,q⃗,r⃗ are L.D. if
αp⃗ + βq⃗ + γr⃗ = 0 has non-trivial solution

Unit vector along a⃗:
â = a⃗ / |a⃗| = a⃗ / √(a₁²+a₂²+a₃²)
🔢 Steps: Prove vectors are coplanar (the master proof)
  1. Write all three vectors in terms of a⃗, b⃗, c⃗ and extract the coefficient matrix: e.g. [1,−2,3], [−2,3,−4], [0,−1,2]
  2. Calculate the 3×3 determinant of coefficient matrix.
  3. = 1(3·2 − (−4)(−1)) − (−2)((−2)·2 − (−4)·0) + 3((−2)(−1)−3·0)
  4. = 1(6−4) + 2(−4−0) + 3(2−0) = 2 − 8 + 6 = 0
  5. Since determinant = 0, the vectors are coplanar. □
⚡ Minimalist Strategy
The coplanar proof is the same structure every time — extract the 3 coefficient rows, compute the 3×3 determinant, show it equals zero. Practise computing a 3×3 determinant quickly using cofactor expansion along row 1. The linear-combination question is just setting up and solving two simultaneous equations — easy 2 marks.

Statistics — Skewness & Karl Pearson's Coefficient
5 marks · [4+1] or [3+2] sub-parts
✅
Q16 is always statistics — skewness. This is pure formula application with a frequency table. No theory derivation needed. If you memorise the two formulas below, this is reliable marks.
PATTERN 1 Calculate Karl Pearson's coefficient of skewness from a frequency/wage table Sets 1, 3, 4, 6 — Dominant pattern
A table of wages / income ranges with number of workers/persons is given. Find mean, mode, SD, then compute Skₚ = (Mean − Mode)/SD. Interpret the result (negative = left skewed, positive = right skewed).
Set 1Set 3Set 4Set 6
PATTERN 2 Examine symmetry using Bowley's or Pearson's skewness; state interpretation Sets 5, 9 — Common
Given raw data or frequency distribution, calculate skewness coefficient and state: if Sk > 0 → positively skewed, Sk < 0 → negatively skewed, Sk = 0 → symmetric. Interpret the distribution shape.
Set 5Set 9
PATTERN 3 Combined mean and variance / Comparing two distributions (CV) Set 8 (Firm A vs Firm B)
Two firms given with n, mean, variance. Find combined mean and combined variance. Also state which firm is more consistent using CV = (SD/Mean)×100.
Set 8
📐 All Essential Formulas
Karl Pearson's Skewness:
Skₚ = (Mean − Mode) / SD

OR (if mode not unique):
Skₚ = 3(Mean − Median) / SD

SD (short-cut method):
SD = h·√[ Σfd²/N − (Σfd/N)² ]
where d = (x − A)/h, A = assumed mean

Mean from table:
x̄ = A + h·(Σfd/N)

CV: (SD/Mean) × 100

Sk = 0: Symmetric
Sk > 0: Positively skewed (tail right)
Sk < 0: Negatively skewed (tail left)
🔢 Steps: Karl Pearson's from a table
  1. Find class mid-points (x). Set assumed mean A = middle class mid-point.
  2. Find d = (x − A)/h where h = class width.
  3. Compute fd and fd² columns. Sum them: Σfd, Σfd², N = Σf.
  4. Mean = A + h(Σfd/N)
  5. SD = h·√[Σfd²/N − (Σfd/N)²]
  6. Find Mode: class with highest frequency; Mode = L + [(f₁−f₀)/(2f₁−f₀−f₂)]·h
  7. Skₚ = (Mean − Mode)/SD. State interpretation.
📋 Typical Answer Structure (Set 3 type)
Given: Income table 0–2, 2–4, 4–6, 6–8, 8–10 (000s) with f = 5,3,8,6,10
Let A = 5 (mid of 4–6 class), h = 2
Compute: Σf=32, Σfd=−10, Σfd²=68
Mean = 5 + 2(−10/32) = 5 − 0.625 = 4.375
SD = 2√[68/32 − (−10/32)²] = 2√[2.125−0.098] = 2√2.027 = 2.847
Mode class = 8–10 (f=10 highest). Mode = 8+[(10−6)/(20−6−0)]·2 = 8.571
Skₚ = (4.375 − 8.571)/2.847 = −1.47 → Negatively skewed
⚡ Minimalist Strategy
Set up the table with columns: x (mid-point), f, d=(x−A)/h, fd, fd². Sum the last three columns. The rest is just plugging into 3 formulas: Mean, SD, Skₚ. The final answer always ends with "positively/negatively skewed" — never skip this sentence, it's a free mark.

Newton-Raphson Method  OR  Mechanics (Forces / Dynamics)
5 marks · Full OR choice
⚠️
Q19 always has an OR option. One option is Newton-Raphson (numerical methods). The other is Mechanics (forces or dynamics). You only need to master ONE side of this OR — pick Mechanics, it is purely formula-based and requires no deep theory.
NEWTON-RAPHSON SIDE Find root of f(x) = x³ − x − 4 = 0 (or similar cubic) in interval (1,2) Sets 1, 4, 6, 9, 10 — Very frequent
Apply x_{n+1} = xₙ − f(xₙ)/f'(xₙ). Start with x₀ = 1 or 2. Iterate 2–3 times. Stop when answer is stable to required decimal places. Answer ≈ 1.796 for x³−x−4=0.
Set 1Set 4Set 6Set 9Set 10
MECHANICS SIDE Two particles/stones meeting on inclined plane or free fall Sets 3, 5 — Common mechanics type
A particle projected up from bottom + another dropped from top. Find when/where they meet. Use s₁ + s₂ = total height. OR: inclined plane — find velocity or time using v²=u²+2as, s=ut+½at².
Set 3Set 5
MECHANICS SIDE Forces: Resultant of two forces P and Q; prove resultant formula Sets 2, 3 — Statics type
Forces P and Q at angle θ. Resultant R = √(P²+Q²+2PQ cosθ). When θ changes or forces interchange, find new resultant or prove tan θ formula. [5 marks]
Set 2Set 3
📐 Newton-Raphson Formula
Formula:
x_{n+1} = xₙ − f(xₙ)/f'(xₙ)

For f(x) = x³ − x − 4 = 0:
f'(x) = 3x² − 1
x₀ = 2 (since f(1)=−4<0, f(2)=2>0)
x₁ = 2 − f(2)/f'(2)
= 2 − (8−2−4)/(12−1)
= 2 − 2/11 = 1.818
x₂ = 1.818 − f(1.818)/f'(1.818)
≈ 1.796
x₃ ≈ 1.796 (converged ✓)
📐 Mechanics Formulas (Dynamics)
Three equations of motion:
v = u + at
s = ut + ½at²
v² = u² + 2as

Free fall: u=0, a=g=9.8 or 10 m/s²
s = ½gt²

Projected upward: a = −g
Max height H = u²/2g
Time to top = u/g

Two-body meeting:
s₁ (down) + s₂ (up) = Total height H
½gt² + (ut − ½gt²) = H → ut = H
🔢 Steps: Newton-Raphson in exam (write these exact steps)
  1. Write: "Let f(x) = [equation]. Then f'(x) = [derivative]."
  2. Check sign change: f(a) and f(b) have opposite signs → root lies in (a,b). Take x₀ = a or b.
  3. Apply formula: x₁ = x₀ − f(x₀)/f'(x₀). Show full calculation.
  4. Apply again: x₂ = x₁ − f(x₁)/f'(x₁). Show calculation.
  5. Apply again: x₃ = x₂ − f(x₂)/f'(x₂).
  6. State: "Since x₂ ≈ x₃ ≈ 1.796, the root correct to 3 decimal places is 1.796."
⚡ Minimalist Strategy
Choose Newton-Raphson — the equation changes slightly between years but the method is identical. The answer for x³−x−4=0 is always 1.796. Even if the equation is different, just follow the 6-step template above, show your working clearly, and you will score 4–5/5. The key examiner trick: always verify the sign change FIRST before starting iterations.

📐 Complex Number Key Formulas
z = a + ib, conjugate z̄ = a − ib
Modulus: |z| = √(a²+b²)
|z|² = z·z̄
a + ib form: multiply num & denom by conjugate

Proof: |x+iy|² = x²+y²
If x+iy = (a−ib)/(a+ib):
Multiply by (a−ib)/(a−ib):
= (a−ib)²/(a²+b²)
Then x²+y² = |x+iy|² = |(a−ib)|²/|(a+ib)|²
= (a²+b²)/(a²+b²) = 1 ✓
📐 Log Identity Proof (Pattern 2)
Given: log x/(y−z) = log y/(z−x) = log z/(x−y) = k

Step 1: log x = k(y−z), log y = k(z−x), log z = k(x−y)

Step 2: Add all three:
log x + log y + log z
= k[(y−z)+(z−x)+(x−y)] = k·0 = 0

Step 3: log(xyz) = 0
∴ xyz = 1 ✓

OR: xˣ·yʸ·zᶻ = 1 (use x·logx + y·logy + z·logz = 0)
🔢 Steps: Form equation with new roots α²β⁻¹ and β²α⁻¹
  1. Given: roots of ax²+bx+c=0 are α, β. So α+β = −b/a and αβ = c/a.
  2. New roots: p = α²/β and q = β²/α.
  3. Sum of new roots: p+q = α²/β + β²/α = (α³+β³)/(αβ) = (α+β)³−3αβ(α+β)) / αβ
  4. Compute using values of (α+β) and αβ from step 1.
  5. Product of new roots: pq = (α²/β)(β²/α) = αβ = c/a.
  6. New equation: x² − (p+q)x + pq = 0. Substitute and simplify.
⚡ Minimalist Strategy
Q20 gives you 3 sub-parts. In the exam, the 2-mark parts (set proof, complex modulus) are straightforward — attempt these first to secure 4 easy marks. The 4-mark part (sequence/log proof) needs the most care. For log ratio proofs, always use the "set each ratio = k" technique — it solves every such problem. For complex modulus proofs, multiply by conjugate.

📐 Angle Bisector Formula
Lines: L₁ = a₁x+b₁y+c₁=0, L₂ = a₂x+b₂y+c₂=0

Bisectors:
(a₁x+b₁y+c₁)/√(a₁²+b₁²)
= ± (a₂x+b₂y+c₂)/√(a₂²+b₂²)

Bisector containing origin:
Substitute (0,0) in each bisector equation and check sign of L₁(0,0)·L₂(0,0).
If same sign → take + sign bisector.
If diff sign → take − sign bisector.
📐 Pair of Lines & 3D Formulas
Angle between pair ax²+2hxy+by²=0:
tan θ = 2√(h²−ab) / (a+b)
Parallel: h²=ab
Perpendicular: a+b=0

Direction cosines (l,m,n):
l²+m²+n² = 1
If DRs = a:b:c then
l = a/√(a²+b²+c²), similarly m, n

Angle between 2 lines:
cos θ = |l₁l₂+m₁m₂+n₁n₂|

Perpendicular: l₁l₂+m₁m₂+n₁n₂=0
🔢 Steps: Find lines from general 2nd-degree equation ax²+2hxy+by²+2gx+2fy+c=0
  1. Compare coefficients: identify a, b, c, h, g, f from given equation.
  2. Check condition for pair of lines: abc+2fgh−af²−bg²−ch²=0. If yes, proceed.
  3. Factorise: treat as quadratic in x (or y). Group terms and factorise into two linear factors.
  4. Example: 6x²−xy−12y²+8x+28y−14=0 → factorise to (2x−3y+7)(3x+4y−2)=0.
  5. Set each factor = 0: Line 1: 2x−3y+7=0. Line 2: 3x+4y−2=0.
  6. Find intersection: solve simultaneously.
⚡ Minimalist Strategy
The bisector question is the most predictable sub-part — it always uses the same ±formula. Write it, substitute, simplify into two separate equations. For direction cosines: DRs a,b,c → DCs = a/√(a²+b²+c²) etc. — this is just one formula applied three times. Even if you can't do the 4-mark factorisation, you can still score 4/8 from the bisector and direction cosine parts.

📐 Condition for Pair of Lines

represents a pair if:

🔢 Steps: Vandermonde / Determinant Proof
  1. Write the determinant clearly. e.g. |1,a,a²; 1,b,b²; 1,c,c²|
  2. Apply R₂ → R₂−R₁ and R₃ → R₃−R₁ (subtract first row from others).
  3. Result: |1,a,a²; 0,(b−a),(b²−a²); 0,(c−a),(c²−a²)|
  4. Factor: b²−a² = (b−a)(b+a). Take out (b−a) from R₂ and (c−a) from R₃.
  5. Expand 2×2 remaining determinant: |1,(b+a); 1,(c+a)| = (c+a)−(b+a) = c−b
  6. Full answer: (b−a)(c−a)(c−b) = (a−b)(b−c)(c−a) ✓
📋 Find k for pair of lines: 2x²−7xy+3y²+5x−5y+k = 0

  • Always state interpretation!
